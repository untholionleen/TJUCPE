# TJUCPE v2.3.0 · 管理员总控与班级创建修复

## 修复内容

1. 班级创建改为明确的 HTML 表单提交，兼容鼠标点击与键盘回车。
2. 新建班级通过 classroom-admin Edge Function 的 create_class 动作完成；服务端验证教师/管理员身份和账号状态。
3. 教师只能将本人设为班级负责人；管理员可以将新班级分配给有效教师或管理员。
4. 成功创建后刷新班级列表、选中新班级并显示加入二维码；失败时展示服务端错误。
5. 管理员专属总控面板保留全平台用户清单、角色调整、启用/停用、邀请教师/学生和密码重置。
6. 新增管理员控制面与班级创建自动化测试。

## 权限边界

- 学生：只能加入班级、提交并管理本人报告。
- 教师：只能管理本人负责班级的教学任务、数据分析和报告批改。
- 管理员：全平台管理教师、学生、班级、任务、实验目录、报告和系统审计。

## 验收说明

教师账号的数据库 RLS 创建策略已通过回滚式 SQL 验证。自动化测试验证服务端角色校验、班级表单绑定和管理员总控入口。真实浏览器端扫码、创建班级、发布任务、提交报告仍需使用测试账号实际操作。
