# Data and plotting reference audit

## What was actually observed in the supplied workbooks

The Excel files were reviewed for sheet names, field labels, representative rows, formulas and embedded charts. The supplied workbooks contained no Excel formula cells in the inspected sheets; many derived values are stored as fixed numeric results. The site therefore does not claim to import hidden formula logic from Excel.

The workbooks did not contain embedded chart objects in the inspected sheets. The Excel column structure, measurement units and series grouping are useful references for building the browser plotting interface; plot styling is additionally informed by the supplied Python plotting script.

## Plotting convention implemented in the first browser release

- Multi-series scatter plot for measured observations (first column X, remaining columns independent Y series), optional line connection for sequential data.
- Linear, quadratic and cubic least-squares polynomial fits.
- Fitted curve drawn separately from immutable raw observations.
- Reported statistics: valid point count, mean Y, sample standard deviation, R² and SSE.
- Residuals visible in the data table.
- Multi-column CSV export for Origin/MATLAB workflows and PNG export for charts. Polynomial fitting is applied to the first Y series; the other series remain measured observations.

The generic regression is a mathematical visualization tool. It does not assert that a polynomial is the physically correct model for every experiment. Select the fit form only when justified by the experiment instructions.

## Gemini plotting script — items to verify before scientific release

The supplied script creates three useful figure concepts:
1. surface tension γ versus concentration c, with a Szyszkowski model;
2. surface excess Γ versus c;
3. c/Γ versus c with a Langmuir linearization.

The script also introduces assumptions that must not silently become authoritative:
- It scales all readings when the first reading exceeds 100, using a pure-water reference of 72.75 mN/m. Instrument units and calibration must be confirmed first.
- It labels the molecular area as 正丁醇分子截面积; the actual solute identity must be checked against the experiment record.
- It uses a particular Szyszkowski parameterization and unit conversion. The concentration basis, temperature, gas constant, surface excess units and linearized fit need independent dimensional checks.
- The adjusted-R² calculation is defined only for positive residual degrees of freedom; scientific reporting should also preserve parameter uncertainty and residual diagnostics.

These advanced calculations are deliberately not auto-generated by the current generic chart tool. They should be added only after source-manual equations and a reference dataset have been checked.

## Provenance requirement for future formula modules

Each production calculation must record the experiment/source version, raw-input snapshot, units, constants, equation version, engine version, calculation timestamp, regression model, residuals and validation status. Never overwrite raw observations with transformed data.
