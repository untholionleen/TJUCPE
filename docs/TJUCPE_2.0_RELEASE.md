# TJUCPE 2.0.0 发布说明

发布日期：2026-11-11
仓库：untholionleen/TJUCPE

## 2.0 功能

1. **学生双文件提交**：实验报告 PDF/DOCX 与数据工作簿 XLSX/XLS/CSV 必须成对提交；重新提交时同时更新两份文件。上传失败会清理本次产生的孤立对象并恢复提交按钮。
2. **实验 Excel 模板**：每项实验的各张数据表导出为独立工作表。首选 SheetJS 生成标准 XLSX；备用路径使用 ZIP/Open XML 生成真正的 .xlsx，不再将文本或 SpreadsheetML 伪装为 XLSX。
3. **模板编制**：教师/管理员可编辑工作表标题和显示表头；数据列 key、数量与顺序校验锁定，不能破坏专属计算引擎。
4. **教师参考数据**：教师按班级和实验项目上传 Excel/CSV；批阅时读取学生原始工作簿并叠加教师参考散点数据。历史 1.0 报告没有数据附件时仍可查看和批阅，不会伪造旧数据。
5. **PDF 批阅**：保留不可变原始 PDF；支持手写圈画、插入文字、修改/删除平台插入的文字、撤销和清空。保存时生成批阅 PDF，并把批注结构和原件路径同步到云端。
6. **回归计算**：不再提供框选/套索选区；线性回归统一使用全部有效数据点。
7. **安全删除班级**：先导出班级数据库资料和所有关联 Storage 文件，确认下载后，服务端验证单次备份凭证并在数据库事务中删除关联记录，随后清理文件。

## 数据与安全

- 报告和 Excel 数据文件继续存放在私有 lab-reports bucket。
- report_submissions.data_file_path 与 data_file_name 随报告版本维护；report_revisions 保留先前报告和数据对象路径。
- 教师参考数据表启用 RLS，权限按管理员或负责班级的教师判断；匿名角色已撤销该表权限。
- class_backup_receipts 仅由服务端 service_role 操作，不提供客户端表访问。
- classroom-admin 维持 JWT 验证开启；删除动作必须提供当前操作者的有效、未使用且已确认下载的备份凭证。
- 原始 PDF 使用 Blob 作为不可变字节来源；PDF.js 和 PDF-Lib 分别使用新生成的 ArrayBuffer，防止 Worker 转移缓冲区后发生 detached buffer 问题。

## PDF 编辑边界

平台新增文字以图层形式写入 PDF 页面，同时保留结构化元数据，支持继续修改/删除平台插入的文字；这不是对 PDF 原有文字对象重新排版的 WPS 级原生文本编辑器。

## 发布后验收

请使用合成账号和测试班级完成：学生双文件提交/重新提交；每个实验 XLSX 用 Excel/WPS 打开；教师保存模板配置；上传参考数据并验证批阅对照图；中文 PDF 文字批注保存后重新打开；全量数据拟合；完整班级 ZIP 下载后删除。不要在真实教学班级上测试永久删除。
